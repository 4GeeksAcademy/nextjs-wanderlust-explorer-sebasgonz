## Referencias visuales

Estas referencias ayudan a definir una interfaz para explorar experiencias de viaje: navegación clara, información fácil de comparar y componentes que se adaptan a distintos tamaños de pantalla. Se toman como inspiración, no como una reproducción literal.

### 1. Stripe

![Icono de estructura de interfaz](https://raw.githubusercontent.com/feathericons/feather/master/icons/layout.svg)

La captura de Stripe presenta una navegación superior sencilla, un titular con jerarquía marcada, llamadas a la acción visibles y una franja de marcas. El área principal combina espacio en blanco con una composición de color intensa. Para Wanderlust Explorer, esta referencia aporta una jerarquía clara y una navegación fácil de recorrer; las fichas de experiencias deben dejar en primer plano el destino, el precio y la valoración.

[Visitar Stripe](https://stripe.com)

### 2. Linear

![Icono de navegación lateral](https://raw.githubusercontent.com/feathericons/feather/master/icons/sidebar.svg)

La captura de Linear muestra una interfaz oscura y sobria, navegación compacta, un titular prominente y una vista de producto que explica el servicio visualmente. Su uso contenido del color mantiene el foco en el contenido. Para el explorador, inspira una navegación rápida y consistente, además de controles discretos que no compitan con las experiencias.

[Visitar Linear](https://linear.app)

### 3. Tailwind UI - Application Shells

![Icono de composición en cuadrícula](https://raw.githubusercontent.com/feathericons/feather/master/icons/grid.svg)

La captura de inicio de sesión de Tailwind Plus organiza el formulario en una columna central, con etiquetas legibles, campos amplios y una acción principal de ancho completo. El fondo oscuro y las líneas sutiles enmarcan el contenido sin distraer. Esta referencia es útil para formularios y vistas de acceso: estructura modular, controles claros y adaptación fluida a pantallas pequeñas.

[Ver Tailwind UI - Application Shells](https://tailwindui.com/components/application-ui/application-shells)

En conjunto, las referencias sugieren priorizar contraste legible, navegación predecible y diseños adaptables. En las vistas de experiencias, las imágenes y los datos esenciales deben seguir siendo fáciles de comparar tanto en escritorio como en móvil.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
